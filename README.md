# CVRP Simulated Annealing Solver

## Java implementation of a Simulated Annealing metaheuristic for solving the Capacitated Vehicle Routing Problem (CVRP).

## Overview

The Capacitated Vehicle Routing Problem (CVRP) is a combinatorial optimization problem in which a fleet of vehicles with limited carrying capacity must deliver goods to a set of customers.

The objective is to construct routes that:

- Visit every customer exactly once
- Respect vehicle capacity constraints
- Start and end at the depot
- Minimize the total transportation cost

Transportation cost is calculated as:

```text
Total Cost = Σ(Route Distance × Vehicle Cost Coefficient)
```

## Algorithm Overview

The solver is based on **Simulated Annealing (SA)**, a metaheuristic inspired by the physical annealing process used in metallurgy.

The algorithm starts from a feasible solution and iteratively explores neighboring solutions while gradually reducing the probability of accepting worse solutions.

### Solution Representation

A solution consists of a collection of vehicle routes where:

- Every customer appears exactly once
- Vehicle capacities are respected
- Every route starts and ends at the depot

### Initial Solution

The search begins from a feasible solution generated using a constructive heuristic.

### Cost Function

The optimization objective is:

```text
Total Cost = Σ(Route Distance × Vehicle Cost Coefficient)
```

Lower cost values correspond to better solutions.

### Neighborhood Operators

New candidate solutions are generated by modifying the current solution through operations such as:

- Customer relocation
- Customer swap
- Inter-route moves
- Route reordering

### Acceptance Criterion

Better solutions are always accepted.

Worse solutions may also be accepted with probability:

```text
P = exp(-(ΔCost) / Temperature)
```

This mechanism allows the algorithm to escape local optima during the early stages of the search.

### Cooling Schedule

The temperature gradually decreases during optimization.

As the temperature becomes lower:

- Exploration decreases
- Exploitation increases
- Acceptance of worse solutions becomes less likely

### Stopping Criterion

The optimization process runs until the provided time limit expires.

```java
long deadline = System.currentTimeMillis() + timeLimitMs;

while (System.currentTimeMillis() < deadline) {
    // improve solution
}
```

The best feasible solution found during the search is returned.

## API

The following classes are provided by the assignment framework and were not modified.

### Instance

Represents a CVRP problem instance.

Methods:

- `getCustomers()` — returns all customers
- `getDepot()` — returns the depot
- `getVehicleCapacity()` — vehicle capacity
- `getVehicleType()` — available vehicle type
- `getDistanceMatrix()` — precomputed distance matrix

---

### Customer

Represents a customer.

Methods:

- `getId()`
- `getX()`
- `getY()`
- `getDemand()`
- `distanceTo(Customer)`
- `distanceTo(Depot)`

---

### VehicleType

Represents a vehicle type.

Methods:

- `getCapacity()`
- `getCostPerUnit()`
- `getCount()`

---

### RouteBuilder

Helper class used to construct routes.

Methods:

- `new RouteBuilder(vehicleType)`
- `add(customer)`
- `canAdd(customer)`
- `getRemainingCapacity()`
- `build()`

---

### Solution

Represents the final solver output.

Methods:

- `Solution.of(List<Route> routes)`

---

### Solver Interface

```java
public interface Solver {
    Solution solve(Instance instance, long timeLimitMs);
}
```

## Constraints

The generated solutions must satisfy all CVRP requirements:

- Every customer must be assigned exactly once
- Vehicle capacities cannot be exceeded
- Every route starts and ends at the depot
- The number of routes cannot exceed the number of available vehicles
- Empty routes are not allowed
